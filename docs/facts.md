# Подтверждённые результаты

Версия: 2026-11-17. Даты ниже относятся к самим проверкам; реорганизация документов не означает повторного сеанса автомобиля. Здесь публикуются наблюдаемые результаты с источником и границами применимости.

## Автомобиль, 2026-11-16

На тестовой машине получены диагностические ответы HU и KOMBI через ENET. Полные обезличенные записи идентификаторов и декодирование SVK — в [отчёте](evidence/2026-11-16-enet-identification.json).

| Блок | Прочитанный идентификатор | Версия |
|---|---|---|
| HU | HWEL 00002fc3 | 001.004.001 |
| HU | BTLD 00001ffd | 007.030.001 |
| HU | CAFD 00001ef6 | 006.052.007 |
| KOMBI | HWEL 000010f7 | 002.001.113 |
| KOMBI | HWEL 000009c6 | 002.001.010 |

Идентификаторы HWEL здесь являются диагностическими данными; каталожные номера деталей и физическое подключение Ethernet ими не проверялись. Значение firmware_menu в отчёте записано со слов владельца, а не прочитано из ОС HU.

При пассивной записи обмена официального Bavarian SSH Client получены положительные ответы UDS 0x71 на routines FD2E, FD2F и FDAC. [Сводка захвата](evidence/2026-11-16-bavarian-hsfz-summary.json) содержит только метаданные и не раскрывает параметры аутентификации. Ответы routines сами по себе не подтверждают работающий SSH. Успешного входа и запуска нашего кода на HU в опубликованных результатах нет.

## Окружение, 2026-11-17

[Отчёт инструментария](evidence/2026-11-17-re-tooling-check.json) и [проверка после переноса проекта](evidence/2026-11-17-project-migration.json) фиксируют:

- Успешную компиляцию примеров C и C++98 в ELF32 ARM QNX. Это сборка, программы на HU не исполнялись.
- Работу Ghidra 12.2 и REA 6.9.0 в Linux ARM64-контейнере; Node 24.22.3, JDK 25.0.5+8.

- Успешные 34 unit-теста на момент переноса. Они проверяют локальную реализацию, а не работу функций на автомобиле.

В историческом отчёте сохранены прежние имена образов clubsport. Текущие команды используют имена nbt-evo; при переносе добавлены новые теги тех же образов, без пересборки.

## Интеграция Bavarian, 2026-11-18

В инструментарий добавлены отдельная загрузка `tools/nbt-env fetch --components bavarian` и офлайн-команды `tools/nbt-bavarian prepare|check|open`. URL и SHA-256 macOS ZIP закреплены по [странице издателя](https://ssh.bavarian-aa.uk/) на указанную дату; changelog сообщает 0.2.3, фактическую bundle version интеграция читает отдельно. [Инструкция](environment.md#bavarian-временный-ssh-на-macos), [lock-файл](../tools/bavarian.lock.json).

Изолированные тесты проверили отказ при повреждении архива/приложения, ZIP path traversal, записи через symlink, ошибке codesign и несовпадении архитектуры; отсутствие загрузок при prepare/check/open и независимость Bavarian-only fetch от Docker и inventory основных компонентов. Полный набор — 82 успешных unit-теста. Использованы синтетические архивы и подмененные macOS-команды. Реальный ZIP этой версии не скачан, подготовка/запуск приложения и временный SSH на HU этой проверкой не подтверждены.

Уточнение 2026-11-18: основной интерфейс сокращен до `tools/nbt-bavarian update` и `tools/nbt-bavarian open`. update получает актуальный хеш из официального SHA256SUMS и фиксирует выбранный выпуск локально после успешной подготовки; open не обращается к сайту. Изолированные тесты проверяют новый выпуск, актуальный кэш, неоднозначный индекс, отказ обновления и восстановление измененной копии. Полный набор после изменения — 87 успешных unit-тестов. Официальный checksum index прочитан; фактическая загрузка/подготовка ZIP и запуск GUI не выполнялись.

## Bavarian: метаданные macOS и codesign, 2026-11-18

В локальной подготовленной копии обнаружен `com.apple.FinderInfo` на корне `.app`; codesign владельца сообщал `resource fork, Finder information, or similar detritus not allowed`. Проверка выполнена на отдельной временной копии уже скачанного архива с SHA-256 из [lock-файла](../tools/bavarian.lock.json), без загрузок и запуска клиента. Исходная копия проходит `codesign --verify --deep --strict`; внесенный тестом FinderInfo воспроизводит отказ. Удаление только FinderInfo/ResourceFork восстанавливает строгую проверку, сохраняя тестовый quarantine и инвентарь байтов/прав файлов. Фактические bundle version/build — `0.2.0`, архитектура — `arm64`. [Обезличенная сводка](evidence/2026-11-18-bavarian-metadata.json); она не содержит путей владельца или данных автомобиля.

Инструмент очищает эти два атрибута перед codesign, в том числе после переноса подготовленной копии. Остальные атрибуты сохраняются, symlink-цели не обходятся. Полный набор — 88 успешных unit-тестов; отдельно выполнена описанная выше проверка реального архива системными командами macOS. Работа GUI и SSH на HU не проверялась.
