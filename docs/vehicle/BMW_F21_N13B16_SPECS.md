# Обезличенный автомобиль для проверок

BMW F21, N13B16. По сообщению владельца, ENTRY_BASIS заменён на NBT Evo с расширенной приборной панелью и MOST; ATM отсутствует. Версия в меню — X20511I.

Измеренные версии блоков и сетевые проверки находятся в [плане NBT Evo](../software/nbt-evo/plan.md) и обезличенных журналах. Сообщение клиента «SSH enabled» получено, но успешного SSH-входа пока нет. Сборка ARM32 QNX проверена на тестовых программах; запуск на HU ещё не подтверждён.

Полное досье автомобиля и исходные идентификаторы остались в частном проекте clubsport. Этот файл содержит только контекст исследования.
